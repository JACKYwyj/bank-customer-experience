# Interactive Demo

A browser-based interactive demonstration of the Bank Customer Experience Enhancement System.

## Access

**Live Demo**: Open `index.html` in any web browser

Or visit the GitHub Pages deployment:  
`https://JACKYwyj.github.io/bank-customer-experience/demo/`

## Features

### Emotion Recognition Simulation
- Text input for customer expressions
- Real-time emotion analysis
- Confidence scoring
- Alert generation

### Quick Test Scenarios
- Waiting Anxiety
- Self-Service Failure
- Complaint Escalation
- Satisfied Customer

### System Visualization
- Multi-modal emotion detection (Text/Facial/Vocal)
- Service flow architecture
- Processing metrics

## Usage

1. Open `index.html` in a browser
2. Enter customer text or select a scenario
3. Click "Analyze Emotion"
4. View results and alerts

## For GitHub Pages Deployment

The demo is located at `docs/demo/`. To enable GitHub Pages:

1. Go to repository Settings
2. Navigate to Pages
3. Set Source to `main` branch and folder to `docs`
4. Access at: `https://[username].github.io/[repo]/demo/`

## Technologies

- Pure HTML/CSS/JavaScript (no dependencies)
- Responsive design
- Works offline
