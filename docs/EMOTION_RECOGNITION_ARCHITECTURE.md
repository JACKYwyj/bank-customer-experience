## 模块说明

### 原始信号采集层
- **摄像头视频流**：实时采集客户面部图像
- **麦克风音频流**：采集客户语音

### 预处理与时序同步
- **滑动窗口**：2秒窗口 + 500ms步长，平衡实时性与稳定性
- **时间戳对齐**：确保视觉和音频数据在同一时间基准

### 视觉支路
| 模块 | 技术方案 |
|------|----------|
| 人脸检测 | YuNet（5关键点输出） |
| 人脸对齐 | 基于关键点的仿射变换 |
| 情绪识别 | MobileNetV3-Small + FER |
| 输出 | 7类情绪置信度向量 |

### 音频支路
| 模块 | 技术方案 |
|------|----------|
| 音频处理 | 16kHz采样、分帧、降噪 |
| 特征提取 | 梅尔频谱（Mel Spectrogram） |
| 情绪识别 | SenseVoice-Tiny |
| 输出 | 7类情绪置信度向量 |

### 多模态融合层
- **动态加权**：
  - 检测到人脸：视觉权重 0.65，音频权重 0.35
  - 未检测到人脸：仅使用音频（纯音频模式）
- **时序滤波**：滑动平均，抑制单帧识别抖动
- **输出**：最终情绪类别 + 强度得分

### 业务应用层
- 银行网点客户情感感知
- 体验分析报告
- 风险预警（投诉风险识别）

## 情绪类别定义

视觉与音频支路统一使用以下7类：

| 编号 | 情绪 | 英文 |
|------|------|------|
| 0 | 愤怒 | angry |
| 1 | 厌恶 | disgust |
| 2 | 恐惧 | fear |
| 3 | 开心 | happy |
| 4 | 悲伤 | sad |
| 5 | 惊讶 | surprise |
| 6 | 中性 | neutral |

## 设计考量

### 为什么选择 Late Fusion（晚期融合）？
1. **灵活性**：各模态独立演进，互不影响
2. **降级策略**：无人脸时自动切换到纯音频模式
3. **实际场景适配**：银行网点光照复杂、人员走动频繁

### 银行场景特殊优化
- 光照变化：考虑在人脸检测前加质量评估模块
- 实时性：500ms步长确保30fps以上的响应频率
- 隐私合规：建议在本地完成推理，敏感数据不出网点
